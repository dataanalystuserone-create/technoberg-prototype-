# TechnoBerg prototype

The design prototype for the TechnoBerg website. Static HTML, no build step:
Vercel serves `index.html` at the root and the other two pages beside it.

| File | Page |
| --- | --- |
| `index.html` | Home |
| `education.html` | Education and talent |
| `course.html` | Programme detail |
| `cybersecurity.html` | Cybersecurity products and solutions |

`hero-field.webp` and `hero-field.jpg` are the hero image. Every other picture
loads from Unsplash over HTTPS.

**This is a prototype, not the delivered website.** It is a design reference
for review and approval. The production site is a separate application and is
built elsewhere.

Prepared by Addonez.
